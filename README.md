# Where-Theres-Rubble-Theres-a-Route
Code used in the paper: "Where There's Rubble, There's a Route". Comparing the APF, RRT* and Hybrid path planning algorithms (with Bezier smoothing and adaptive stuck-detection) in the context of post-disaster environments where initial reconnicance is done and the terrain is now static. Built in Python with modular simulation and analysis scripts.
